# NF512-Unidad6-Ejercicio6.2b-CSHARP

TempoControl es un sistema de gestión de fichaje (ponchado) de empleados desarrollado para Innovatech Solutions, S.R.L. Su propósito es reemplazar el proceso manual de control de asistencia basado en hojas de Excel, permitiendo al personal de Recursos Humanos registrar entradas y salidas de los empleados de forma centralizada, confiable y eficiente.
La aplicación está construida como una aplicación de consola en C# con .NET 10, utilizando SQLite como motor de base de datos. La arquitectura sigue el Patrón Repositorio con separación clara en cuatro capas: Dominio, Acceso a Datos, Lógica de Negocio y Presentación.
